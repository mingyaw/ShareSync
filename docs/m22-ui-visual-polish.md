# M22 UI Visual Polish

Status: Complete light visual polish pass.

M22 keeps the existing native UI implementation and improves hierarchy without introducing a custom design system.

## Changes

- Android panels now use product-oriented section titles and ordering.
- Main actions appear before pairing/support details.
- Connection and support controls are visually separated from the photo status path.
- iOS copy and action labels now use support/product language instead of implementation language.
