# M49 Platform Compliance Package

Status: Complete source-code checkpoint.

iOS includes local-network, Bonjour, camera, and Photos usage descriptions plus
a bundled `PrivacyInfo.xcprivacy`. The manifest declares no tracking or collected
analytics data and records the app's UserDefaults and disk-space required-reason
API usage. Android declares image access, notification, network, and data-sync
foreground-service permissions, disables application backup, and keeps the
service non-exported.

Store listing answers, signing certificates, screenshots, privacy-policy URL,
and final App Store/Google Play review remain release-operations work.
